# DSH 会话清理（Windows 桌面版）

针对 DSH 0.2.2-rc.5 的 JSONL 存储。**永久删除一个已归档、无父子关系的独立会话的当前日志；不是清理整个工作区，也不是安全擦除。**

DSH 没有提供删除会话的接口，所以本插件用两个组件完成：会话行菜单只负责选中并复制 ID，独立的 Windows 助手负责预览与执行。真正删除时它持有 DSH 写入该会话所用的同一把锁，并校验文件内容哈希，因此有写入者或内容已变化时会拒绝，而不是写坏数据。

## 使用

1. 在 DSH 的「插件 → 添加插件」选择本目录安装（无需 npm），然后完全退出并重开一次 DSH。启动器会优先使用桌面版自带的 Node 运行时，再找 PATH 上的 Node。
2. 归档目标会话，在侧栏「视图」选择「仅显示已归档」，在该行「⋯」菜单点「准备清理…」。它只复制会话 ID。
3. **保持 DSH 打开**，双击本目录的「清理助手.cmd」。助手自动读取剪贴板里的 ID（直接回车），显示目标文件路径与日志大小。
4. 输入 `y` 回车。助手会先向 DSH 重新核验一次，再删除这一份日志。
5. 回 DSH 按 F5 刷新侧栏；该行消失即完成。若仍显示，完全退出再打开 DSH。

**删除不进回收站**；需要备份请先取消并自行导出。失败时不要手工删目录。

## 范围与拒绝条件

仅支持本机、Windows 固定 NTFS 卷、JSONL v4 单一规范日志（原始或 Zstandard）。以下情况一律拒绝：历史多代日志、未归档、子代理、分叉、拥有子会话、特殊或不确定的存储布局、硬链接或符号链接、预览后内容被改动、文件仍有写入者或被占用。不会删除工作区、其他会话、全局索引、上传附件、备份或云副本，也不执行数据库压缩。

## 已知限制

- 删除后侧栏或搜索可能仍短暂显示该会话，刷新或重开 DSH 后消失；搜索索引在下一次查询时对账。
- 预览显示的日志大小不等于磁盘实际释放的空间。
- 这不是安全擦除，也不是全局锁；同一存储上仍可能有绕开插件的写入者。

## 权限与数据流

浏览器只复制已选择的 ID，没有文件路径参数、执行权或模型工具。Host 通过 DSH 的归档集合与持久化快照核实选择。握手与签名计划落在当前 Windows 用户的 `%LOCALAPPDATA%\DshSessionCleaner-v1`，依赖该用户目录的访问控制；计划只保存 ID、路径、元数据与目标哈希，不保存聊天正文。助手与插件都不递归删除目录。

## 开发与验证

- `core.cjs` 是唯一的删除实现；`core.test.cjs`、`bundle.test.cjs` 共 10 项测试覆盖：计划签名与篡改、内容变化、父子会话、多代日志、硬链接拒绝、被占用时拒删、删除指定合成日志并保留相邻文件。
- 未在真实用户会话上试删。

若 DSH 存储格式或默认后端发生变化，请勿绕过拒绝检查。
