# DSH 会话清理（Windows 桌面版）

针对 DSH 0.2.2-rc.5 的 JSONL 存储。**在侧栏会话行点一下就能永久删除该会话的日志，列表随即移除。** 不是清理整个工作区，也不是安全擦除。

DSH 本身没有删除会话的接口，所以本插件在 Host 侧执行删除，并通过 DSH 自己的同源 API 通道把结果返回页面：

1. 行菜单「永久删除…」→ 浏览器原生确认框（显示标题与 ID）。
2. Host 校验：会话已归档、无父子关联、当前格式、单一日志代。
3. 删除时持有 DSH 写入该会话所用的同一把信号量，并以独占句柄重算 SHA-256；有写入者或内容变化即拒绝。
4. 删除后再次确认文件确实不存在，再让页面刷新会话列表，该行消失。

## 使用

1. 在 DSH 的「插件 → 添加插件」选择本目录安装（无需 npm），然后**完全退出并重开一次 DSH**，让客户端与 Host 载入当前版本。
2. 归档要删的会话，在侧栏「视图」选「仅显示已归档」，在该行「⋯」菜单点「永久删除…」。
3. 确认框核对标题与 ID，点确定；成功会提示删除了多少字节，该行随即消失。

失败时提示会说明原因（未归档、仍有写入者、日志被改动、存储布局不受支持等），此时**不会**删除任何文件。

## 备用路径（页面删除不可用时）

若 API 路由不可用（例如先前的安装、或 DSH 版本变化），仍可用外部助手：行菜单复制 ID → 双击本目录的「清理助手.cmd」→ 回车 → 输入 `y`。助手在删除前会重新向 DSH 核验。

## 拒绝条件

仅支持本机、Windows 固定 NTFS 卷、JSONL v4 单一规范日志（原始或 Zstandard）。以下一律拒绝：未归档、子代理、分叉、拥有子会话、历史多代日志、特殊或不确定的存储布局、硬链接或符号链接、预览后内容被改动、文件仍有写入者或被占用。不会删除工作区、其他会话、全局索引、上传附件、备份或云副本。

## 已知限制

- 删除后搜索索引在下一次查询时对账，可能短暂仍可命中。
- 预览/提示里的日志大小不等于磁盘实际释放的空间。
- 不是安全擦除，也不是全局锁。

## 权限与数据流

页面不携带文件路径参数，也不获得执行权；它只把会话 ID 发给 `/api/session-cleaner/delete`，该路由经 DSH 的认证与 Host/Origin 校验后才执行。删除实现只有一个（`core.cjs`），页面路径与外部助手共用同一套校验。计划与失效标记落在 `%LOCALAPPDATA%\DshSessionCleaner-v1`，只保存 ID、路径、元数据与哈希，不保存聊天正文。

若 DSH 存储格式、命令或 API 通道发生变化，请勿绕过拒绝检查。
